# Development status and transparency
Reviewed: 13 October 2026 · restricted beta 0.7.70.

The canonical public status is on the [transparency page](https://sophia-pharmacy.enricogiuliano.chatgpt.site/transparency); the [roadmap](https://sophia-pharmacy.enricogiuliano.chatgpt.site/roadmap) sets out priorities and completion criteria. The two interactive buildings share the same assessment snapshot. Scores are qualitative internal maturity judgments, not accuracy percentages, certifications or clinical validation.

The latest foundation work improves the configured storage adapter, personal-data export and the technical rights workflow, with deadline ordering, pagination and recorded outcomes. Checks include network-blocked application tests, synthetic browser checks and Firestore integration on isolated staging using temporary synthetic records. This work does not involve new model answers or independent clinical evaluation.

Retention decisions, effective supplier evidence, privacy/regulatory qualification, administrative access verification, reviewer qualification/training and a full cloud restore exercise remain open. The public roadmap keeps these requirements visible; the pilot is not declared completed.

This repository is a collaboration and documentation space. Application source, private conversations and operational security details are kept out of public materials. To participate, use the [collaboration opportunities](../COLLABORATION.md) or the [20-question pilot proposal](../pilot/README.md).

For the current state, read the linked website rather than interpreting the age of this note as a new review. This note must be reconciled after a documented release or public status update.
